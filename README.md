# AGROSCOPE web sitesi

Yedi temel menü değil, sekiz temel menü ve 15 sayfa içeren statik site. Yayın adresi: https://erdoganenestr.github.io/agroscope-site/

Menüler: Anasayfa, Hakkımızda, Hizmetlerimiz, Ürünlerimiz, Referanslarımız, Blog, İletişim, Kariyer.

Drone, motor ve arazi görselleri temsili olarak üretilmiştir. Ürün fotoğrafı veya gerçek saha sonucu değildir. Logo proje sahibinden alınmıştır. Referans ve kariyer içerikleri doğrulanmamış isim veya pozisyon belirtmez.

Özel alan adı `agroscope.com.tr` için İHS DNS sorunu destek talebi 1078964 ile takip ediliyor. DNS düzelince GitHub Pages ayarından alan adı eklenmeli ve HTTPS etkinleştirilmelidir.
